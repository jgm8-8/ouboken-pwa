# Ouboken PWA 1.2.1

応募券のコード①・②を順番にコピーするためのiPhone用ツールです。公開URL：[Ouboken](https://jgm8-8.github.io/ouboken-pwa/)。写真追加・OCR・保存・ZIP出力は端末内で処理します。コードの管理・ZIP出力にPC・APIキーは不要です。応募サイトの自動入力・送信は行いません。

## 使い方

1. Safariで公開URLを開き、共有から「ホーム画面に追加」。ホーム画面側で使います。
2. ホームの「共通のキャラ」を選び、応募券の写真を追加。
3. 「コード確認」で券面と照合。読めない箇所は手入力。
4. 「ZIPにまとめる」からファイルを出力。
5. ZIP内の `コピー一覧.txt` と `次の位置.txt` を、既存ショートカットで使うOubokenフォルダへ保存。交換時は2ファイルとも置き換えます。

コピー一覧は「1枚目のコード① → 1枚目のコード② → 2枚目のコード① → 2枚目のコード②」の改行区切りです。先頭ゼロを保持し、余分な空白・空行は付けません。住所・回答・キャラ名・写真はZIPへ含めません。`次の位置.txt` はショートカットの読み取り位置を1へ戻すファイルです。

## キャラと応募記録

共通のキャラは未出力の券に適用します。ZIPを作成した時点で券ごとにキャラを記録するため、その後に共通のキャラを変えても、出力済み・応募済みの券は変わりません。券ごとの指定がある場合はそちらを使います。

「応募券一覧・履歴」で、各コードのキャラ、状態、キャラ別の全枚数と応募済み枚数を確認できます。検索・状態の絞り込み中でも、上の集計は全応募券が対象です。未応募・結果不明は応募済み枚数に含めません。旧版でキャラを記録していなかった券は「未記録」と表示し、現在の共通キャラを勝手に割り当てません。

応募を終えたら個別画面のステータス、または一覧の「選択」→「ステータス変更」で応募済みとして手動記録します。ツールは応募サイトの受付結果を確認しません。個別画面のキャラ選択で記録を訂正でき、訂正前の内容は履歴に残します。

## 任意の自由記述・AI整形

応募券一覧から個別画面を開き、「自由記述・AI整形（任意）」を展開します。感想・要望／イベント／新商品の3項目を入力・コピーできます。「文章を整える」はGPT5-nanoで整形し、元の文章と候補を比較してから採用できます。APIキー設定もこの個別画面の中にあり、キーは端末内に保持します。

文章は券ごとの下書きとして自動保存します。未入力でもZIPを出力でき、入力・AI整形・採用・コピーでコードの確認状態、キャラ、応募記録、コード専用ZIPは変わりません。応募済みの券でも文章の補助だけ使えます。整形失敗時は元の文章を維持します。文章を整える操作時のみ、選んだ項目の文章をOpenAIへ直接送信します。API利用料はキーの所有者にかかります。

下書きは写真などと一緒にバックアップへ含めます。以前の個別回答や応募時の自由記述も初期値として引き継ぎますが、下書きの編集で過去の応募記録を上書きしません。APIキーはバックアップには含みません。

## 写真・保存・バックアップ

- 写真はJPEG・PNG・WebPに対応。HEICはJPEGへ変換してください。最大150枚／回・各25MB。最大辺2000pxへ縮小し、1枚ずつ読み取ります。
- OCRはPP-OCRv4を同梱。0とO・1とIなどは券面で確認してください。読めなくても写真を残し、手入力できます。同じ写真・コードの重複を通知します。
- 一覧は160px以下のサムネイルを必要になる位置で読み込みます。不要な券は確認後に削除でき、写真・切り抜き・サムネイルも整理します。
- 写真・コード・キャラ・履歴はブラウザのIndexedDBへ自動保存。設定で容量、キャッシュ削除・再準備を操作できます。アプリ更新は現行版と最新の待機版だけを保持します。
- トップの「バックアップを作成」「バックアップから復元」で保存・復元できます。ファイル名と復元画面に日時・枚数を表示。パスワードなしの `.ouboken` 形式です。
- 旧版で入力した住所・回答・履歴は削除せず、内部とバックアップに保持します。住所や選択式の回答は現行画面とショートカット用ZIPには出しません。以前の自由記述は文章補助フォームへ引き継ぎます。以前保存したAPIキーもバックアップには含みません。
- 「全データを削除」は、以前の入力情報や保存済みAPIキーも含め、この端末の保存データを削除します。確認画面から先にバックアップを作成できます。ダウンロード済みファイルとアプリキャッシュは残ります。

Safariの閲覧データ削除や端末交換で保存領域を失う場合があります。バックアップは「ファイルに保存」まで行ってください。Safariのタブとホーム画面アプリで保存領域が分かれる場合は、使う側でバックアップを復元します。すべての領域と検知記録が同時に消えると、初回利用と区別できません。

## 開発・公開

このフォルダは、元のPython / Windows EXE版から独立しています。公開するのはこのプロジェクトだけです。親の `data`、`img`、EXE、応募者情報やAPIキーを含めないでください。

Node.js 24 / pnpm 11.25.0で実行します。

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm build
pnpm preview
pnpm package
```

プレビューは `http://127.0.0.1:8773/`。`release/ouboken-pwa-pages.zip` は公開用ビルド、`release/ouboken-pwa-source.zip` はソースです。配布ZIPに端末内の利用者データは含めません。

公開リポジトリは `jgm8-8/ouboken-pwa`。GitHub PagesのSourceをGitHub Actionsにし、`main` へのpushでテスト・ビルド・公開を行います。サイトへアクセスできる人は利用できますが、各端末のデータはブラウザ内に保存します。

旧版の住所・回答の一括出力は互換性と復帰用のソース・テストとして残し、現行UIからは使用しません。AI整形は個別画面の任意の文章補助として使えます。旧パスワード付きv1バックアップは旧版で復元し、パスワードなしv2として保存し直す必要があります。
